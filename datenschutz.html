Welche Daten verarbeitet die App?

  • Eigene Timer und Namen der Teilnehmer (Sparring-Rotation) werden ausschließlich lokal auf deinem Gerät gespeichert. Sie werden nicht an uns oder Dritte übertragen. Beim Löschen der App werden sie entfernt.
  • Mitteilungen: Damit die Glocke auch bei gesperrtem Handy kommt, plant die App lokale Mitteilungen auf dem Gerät. Es werden keine Push-Dienste oder Server genutzt.
  • Sprachansage: Die Ansage der Paarungen erzeugt die Sprachausgabe von iOS direkt auf dem Gerät.

Was die App nicht tut

  • Kein Account, keine Anmeldung
  • Keine Analyse-, Tracking- oder Werbe-Dienste
  • Keine Internetverbindung erforderlich, keine Datenübertragung an Server
